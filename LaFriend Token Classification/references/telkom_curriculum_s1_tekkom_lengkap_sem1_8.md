## 📌 KELOMPOK MATA KULIAH PILIHAN (ELECTIVES / PEMINATAN S1 TEKNIK KOMPUTER)

Mahasiswa di Semester 6, 7, dan 8 dapat mengambil mata kuliah pilihan sesuai dengan jalur spesialisasi:

### 1. Bidang Keahlian: Cyber Security & Jaringan Cerdas
- **Komputer Forensik**: *Digital Evidence Acquisition, File System Forensics (NTFS/FAT/EXT), Memory Volatile Forensics (Volatility), Network Packet Forensics, Chain of Custody, Laporan Legal Bukti Forensik Digital.*
- **Kriptografi Terapan**: *Teori Bilangan Modular, Algoritma Stream Cipher & Block Cipher, Elliptic Curve Cryptography (ECC), Zero-Knowledge Proof, Kriptografi Pasca-Kuantum Dasar.*
- **DevSecOps (Developer Security Operations)**: *Integrasi Keamanan pada CI/CD Pipeline, Static Application Security Testing (SAST), Dynamic Testing (DAST), Manajemen Rahasia & Kredensial, Container Security Hardening.*
- **Audit Teknologi Informasi**: *Framework COBIT & ISO 27001, Penilaian Kepatuhan IT Governance, Risk Assessment & Maturity Model, Evaluasi Kontrol Keamanan Internal Organisasi.*

### 2. Bidang Keahlian: Embedded Systems, Robotika & IoT
- **Perancangan Sistem VLSI & FPGA**: *Arsitektur FPGA Xilinx/Altera, Pemrograman Hardware VHDL / Verilog Lanjut, Sintesis Sirkuit Digital, Pipelining Hardware, Simulasi Timing ModelSim.*
- **Robotika Lanjut**: *Sensor Fusion (Extended Kalman Filter), SLAM (Simultaneous Localization and Mapping), Algoritma Path Planning (A\*, RRT, Dijkstra 2D Grid), Computer Vision untuk Robot (OpenCV Object Tracking).*
- **Desain Perangkat Keras PCB Lanjut**: *Desain PCB Multi-Layer Frekuensi Tinggi, Manajemen Integritas Sinyal & EMI/EMC Shielding, Routing Jalur Diferensial Impedansi Terkontrol, Fabrikasi PCB & Surface Mount Technology (SMT).*

### 3. Bidang Keahlian: Intelligent Computing & Big Data
- **Pembelajaran Mendalam (Deep Learning)**: *Convolutional Neural Networks (CNN untuk Klasifikasi Citra & Deteksi Objek), Recurrent Neural Networks (RNN & LSTM untuk Data Sekuensial), Transformer Architecture & Self-Attention, Framework PyTorch & TensorFlow, Model Optimization (Quantization & Pruning).*
- **Teknologi Big Data & Komputasi Terdistribusi**: *Ekosistem Apache Hadoop & HDFS, MapReduce Programming Model, Apache Spark Dataframe & RDD, Streaming Data Processing Apache Kafka, Arsitektur Data Warehouse & Data Lake.*
- **Pemrosesan Citra Digital**: *Operasi Titik & Histogram Equalization, Filtering Spasial (Konvolusi Gaussian, Sobel, Canny Edge Detection), Transformasi Fourier 2D, Segmentasi Citra (Thresholding Otsu, K-Means), Ekstraksi Fitur Morfologi Citra.*
