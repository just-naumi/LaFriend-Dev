# LaFriend

LaFriend is a need-driven study partner discovery and group formation platform for Telkom University students.

## Technology Stack

- Backend: Python + FastAPI
- Database: SQLite
- Frontend: HTML + Bootstrap 5

## Main Features

- Student Study Intent creation
- Study Intent management (Active, Cancel, Details)
- Available Time Slots with Priority
- Session Matching (Upcoming)
- Partner Matching (Upcoming)
- Explainable compatibility scoring (Upcoming)
- Study group formation (Upcoming)

## Project Structure

- `backend/`: API and business logic (FastAPI, SQLAlchemy, Pydantic)
- `frontend/`: User interface (Bootstrap 5, Vanilla JS)
- `database/`: Local database storage (`lafriend.db`)
